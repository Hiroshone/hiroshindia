# India coverage directory

Source: Ministry of Panchayati Raj, Local Government Directory (https://lgdirectory.gov.in/).
Snapshot: 23Sep2026. License: Government Open Data License - India (GODL-India).
Mirror: https://github.com/ramSeraph/opendata
Normalised dataset: https://india-lgd-index-api.vercel.app/v1/states and /v1/districts
Downloaded: 16 October 2026. 36 states/UTs and 784 districts.

This is a dated snapshot, not a claim of current administrative completeness. Preserve source metadata when refreshing. Validate unique district codes, state relationships and counts before replacing it. No live third-party API is called by visitors.

The static service-areas.html includes every district in the snapshot and works without JavaScript. coverage.js adds filtering. State sections use anchor links, not duplicate indexed state/district pages. District quote links prefill either pickup or delivery; free-text locations remain available. PIN validation checks format only, not postal existence or serviceability.
